# Bài test Trung Tâm Khai Sáng

## Đăng lên GitHub Pages
1. Tạo một repository mới trên GitHub.
2. Upload `index.html` vào thư mục gốc của repository.
3. Vào **Settings → Pages**.
4. Chọn **Deploy from a branch**.
5. Chọn branch `main` và thư mục `/ (root)`, rồi bấm **Save**.
6. GitHub sẽ tạo đường dẫn website sau khi deploy xong.

> Lưu ý: website là HTML tĩnh. Chế độ giáo viên được khóa ở phía trình duyệt nên không nên xem đây là cơ chế bảo mật mạnh nếu repository được công khai.
